# D3Vision v1.0.0

Initial packaged release of the .NET 8 / WPF Diablo III desktop overlay.

- Compact game-aligned widgets, skill countdowns and configurable overlay appearance.
- Experimental nearby-map geometry, colour-coded elite markers, and legendary/set
  item stars with brighter Ancient markers and red circled Primal pentagrams.
- Optional skill auto-cast and Kadala multi-buy activation by hover or click.
- Myriam gear/enchant reference using EU seasonal normal solo Greater Rift builds,
  with an inventory-style gear layout and actual source rank displayed.
- Windows installer with bundled .NET 8.0.32 Desktop Runtime, Start-menu shortcuts,
  optional desktop shortcut, and uninstall that preserves user settings/history.

## Installation

Download `D3Vision-Setup-1.0.0-win-x64.exe` from the release assets, close any running
D3Vision instance, and run the installer. Requires Intel/AMD x64 Windows 10 version
2004 (build 19041) or newer, or Windows 11. Use Diablo III Windowed (Fullscreen)
or Windowed mode. F10 toggles visibility, F11 toggles click-through, and F12 opens
settings. The installer is unsigned and may display an unknown-publisher warning.

## Validation and limits

All 172 automated checks passed. An isolated installer build verified all 470
payload file hashes, removal of installed payload files, and retention of user-added
files. That validation build suppresses registry changes, shortcuts and running-app
checks; these integration points and Windows 10 hardware remain unverified.

Native map/actor reading is restricted to the validated Diablo III 2.8.0.99920
executable. Party element strips are visual layout only. Visual cooldown reading
is experimental and needs calibration. OCR requires a supported installed Windows
language pack; Kadala/Myriam detection expects English UI. Fresh Myriam build data
requires Internet access. Gameplay input acceptance, extended performance, Primal
markers and mixed-DPI hardware still need further live validation. See README for
feature-specific limitations and controls.
