# D3Vision v1.1.0

Portrait buff indicators and skill-target alignment fixes for Windows 10/11 x64.

## Changes

- Replaced the visual-only party element strips with live Convention of Elements
  portrait glows, with an optional coloured ring-symbol mode. Independent cycles
  were observed on Barbarian and Crusader characters.
- Added Squirt's Necklace indicators and stack counts. Confirmed zero stacks show
  a red cross. Remote powers remain visible at zero when power presence is known;
  `*` distinguishes an observed power from confirmed worn equipment.
- Corrected native buff attribute indexing and automatic local-player portrait
  mapping, including when the local hero occupies a nonzero game slot.
- Fixed three-second skill hover targeting to use only calibrated skill artwork.
  Countdown text, hover feedback and AUTO outlines anchor to each skill box.
  Overlapping boxes, stale/mismatched capture geometry, changed capture modes,
  monitors and aspect ratios no longer arm the wrong skill.
- Improved guardian identification and excluded pets/scenery from encounter
  selection. Expanded boss tracking to 120 units for ranged characters.
- Added bounded, read-only buff diagnostics and an illustrative portrait preview.

## Update instructions

Close D3Vision using F12 > Exit D3Vision before installing this update. Download
the installer EXE or the ZIP containing that installer, its checksum and instructions.
The .NET 8 Desktop Runtime is included; settings and history are preserved.

After updating, use F12 > Calibrate ready skill icons and save all six skill boxes
again. Legacy calibration lacks capture-mode metadata and cannot arm hover toggles.
Use F11 to align/resize the new portrait frames. F12 offers portrait-glow or ring
mode and automatic/explicit player-slot mapping.

## Stricken: next fix, not validated as a finished feature

The experimental Stricken estimate and diagnostic support are included, but a live
counter increment has not been validated. Proc flags were observed; exact enemy
stack counts are not exposed by this reader. Any `~` value is an observed proc
estimate near an identified boss, and procs can hit other enemies. It must not be
treated as an exact boss stack count. Controlled solo boss validation and any
resulting Stricken corrections are the next planned fix.

## Validation and remaining limits

223 automated checks passed. The installer verification checks payload hashes,
uninstall and retention of user-added files in an isolated workspace install.
The verification variant suppresses registry changes, shortcuts and running-app
checks; these integration points and Windows 10 hardware remain unverified.

The installer is unsigned and Windows may show an unknown-publisher warning.
Requires Intel/AMD x64 Windows 10 build 19041 or newer, or Windows 11. Native
readers support only the validated Diablo III 2.8.0.99920 executable. Windowed
(Fullscreen) or Windowed display mode is required. Mixed-DPI hardware, extended
gameplay performance, live zero-stack Squirt cross transitions, live Primal markers,
and real-game input acceptance still need further validation. See README and
docs/Portrait-buff-validation.md for details.
