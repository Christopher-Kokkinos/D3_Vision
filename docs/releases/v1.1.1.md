# D3Vision v1.1.1

Solo-validated Stricken proc estimates, clearer portrait readouts and capture replay coverage.

## Changes

- Integrated the successful solo Stricken capture into regression coverage for the
  live counter already introduced in v1.1.0. The app's portrait counter uses the
  same tracker exercised by the recording and replay.
- Stricken now shows **ready** when the gem is equipped and no nearby guardian is
  selected, **~N** for an observed proc estimate during the encounter, and **?**
  when a selected encounter's count is unavailable. It clears after the guardian
  disappears instead of retaining a previous fight's count.
- Preserved a normalized 144-sample solo encounter as a regression fixture without
  process IDs, player names, coordinates or raw capture files.
- The installer build now also generates the release ZIP and checksum. Isolated
  installer verification uses uncompressed payloads to avoid redundant compression.

## Live validation

A solo Barbarian Greater Rift recording captured a guardian encounter spanning
approximately 12.3 seconds. The estimated counter increased **0 to 16**, then cleared
on the first sample after guardian disappearance, even while a proc flag lingered.
Confirmed worn Squirt's Necklace readings covered every stack value **0 through 10**.

This validates observed proc tracking and native Squirt state readings. **It does
not confirm sixteen exact enemy stacks.** Sampling can miss short events, procs can
hit other enemies, and this reader does not expose authoritative target stack totals.
The `~` estimate and these limitations remain deliberate parts of the UI.

## Installation and upgrade

Close the current overlay using F12 > Exit D3Vision. Download the installer EXE or
the ZIP containing the same installer, checksum, instructions and these notes.
The .NET 8 Desktop Runtime is included; settings and history are preserved.

Upgrading from v1.0.0 requires re-saving all six ready skill calibration boxes in
F12 before using hover toggles. Existing v1.1.0 capture-mode calibration remains
compatible. Use F11 to align portrait frames if needed.

## Verification and remaining limits

230 automated checks passed, including live encounter replay and ready/estimated/
unknown/unequipped readout states. Installer verification checks every installed
payload hash, uninstall, and retention of user-added files in an isolated directory.
The verification variant suppresses registry writes, shortcuts and running-app
checks; those integration points and Windows 10 hardware remain unverified.

The installer is unsigned. Requires Intel/AMD x64 Windows 10 build 19041 or newer,
or Windows 11. Native readers remain restricted to Diablo III 2.8.0.99920.
Windowed (Fullscreen) or Windowed display mode is required. Mixed-DPI hardware,
extended performance, live Primal markers, and exact Stricken target attribution
still need further validation. No new gameplay inputs were generated during testing.
