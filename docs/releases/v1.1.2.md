# D3Vision v1.1.2

Patch release covering skill autocast, Myriam visibility and rapid inventory actions.

## Changes

- Fixed skill hover targeting using physical cursor coordinates and rendered dot hit boxes. Added visible three-second countdowns and red/green armed indicators.
- Added potion autocast (default D), seven-slot calibration, scan-code keyboard input and clearer blocked-input status. Improved dark-icon recognition and kept OCR work separate from the capture loop. Game-window capture is recommended for readable cooldown icons.
- Made the Myriam guide smaller and click-through; F9 hides/shows the guide without hiding the rest of the overlay.
- Added opt-in Blacksmith salvage-all and selective salvage that preserves Ancient/Primal items and skips unknown ranks or unsupported equipment.
- Added opt-in backpack DROP after a three-second hover. This includes Ancient and Primal backpack items.
- Added rapid foreground window-message clicks to DROP and salvage, with item identity/removal checks and recognised salvage confirmations. Reduced capture/OCR overhead using a dedicated capture worker and focused OCR regions.
- Updated Kadala multi-buy to short bursts of up to four purchases, with local-backpack progress checks. Both three-second hover and single-click activation remain available.
- Preserved minimap alignment and rendering. If a saved configuration hides it, enable the Rift Map widget in Settings.

## Validation and limitations

461 automated checks passed, including foreground/cancellation guards, balanced mouse messages, client-coordinate bounds, inventory rank filtering, capture ownership and skill targeting. Release packaging also verifies installed payload hashes, uninstall and retention of user-added files in an isolated directory. That installer check omits registry/shortcut integration and running-app checks.

The user confirmed skill activation with game-window capture. Rapid DROP, salvage and bulk Kadala purchases have automated coverage but have not been exercised against live inventory during this release's validation. They are sequential actions, not an atomic game command; game processing and salvage confirmations affect completion time. Stop with Escape or by leaving the game. Kadala stops after no inventory progress, including full inventory or insufficient shards.

Stricken remains an observed proc estimate, not an authoritative target stack count. Native readers remain limited to Diablo III 2.8.0.99920. English UI recognition and the standard desktop HUD are required for vendor automation. Performance targets and mixed-DPI/Windows 10 hardware remain unverified.

## Installation

Close D3Vision via F12 > Exit D3Vision. Extract the ZIP and run the included installer. Windows 10 build 19041+ / Windows 11, Intel/AMD x64; .NET 8 Desktop Runtime is included. Settings and history are preserved. The installer is unsigned.

The ZIP includes this release's notes, CHANGELOG.md, installation instructions and checksums. Re-save ready skill calibration in game-window capture mode as needed; include potion D to use its toggle. Re-arm autocast after restarting.
