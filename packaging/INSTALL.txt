D3Vision for Windows 10/11 (Intel/AMD x64)

Requires Windows 10 version 2004 (build 19041) or newer, or Windows 11.
The .NET 8 Desktop Runtime is included. No separate .NET installation needed.
Install for the current Windows user; administrator access is not required.

Close D3Vision before installing an update or uninstalling.
Launch D3Vision from the Start menu. Use Diablo III Windowed (Fullscreen)
or Windowed display mode.

F10: show/hide overlay
F11: toggle click-through/editing
F12: settings (including Exit D3Vision)

Windows OCR requires an installed supported Windows OCR language pack.
Kadala and Myriam screen detection currently expects the English game UI.
Fresh Myriam build information needs Internet access; cached builds work offline.
Experimental native map/actor reading supports Diablo III build 2.8.0.99920 only.

Settings, statistics and session history are stored in %LOCALAPPDATA%\D3Vision.
Uninstall preserves these files and any user-added files in the install folder.
This installer does not include user settings, captures, or developer tools.

Updating to 1.1.1:
Save all six ready skill calibration boxes again in F12 before using hover toggles.
Use F11 to align the new portrait frames. Live CoE glow/ring mode is selected in F12.
Stricken ready means equipped and waiting for a guardian. A ~ value is an estimated
proc count during the encounter. A solo capture validated 0 to 16 and reset after
guardian disappearance; exact enemy stack totals are not exposed by this reader.
